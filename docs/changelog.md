# Changelog

All notable changes to this repository are recorded here. Changes to the
**canonical artifact** create a new version and never alter prior versions
(see [GOVERNANCE.md](GOVERNANCE.md)). Format follows *Keep a Changelog*.

## [1.0] — 2026
### Canonical
- Established the Proclamation of Individual Equity as the canonical Version 1.0
  artifact, from the authoritative parchment.
- Added verbatim plain-text, Markdown, and PDF renderings.

### Infrastructure
- Canonical metadata record (`metadata/misty.json`); derived Zenodo, DataCite,
  `codemeta.json`, and `CITATION.cff`.
- SHA-256 integrity manifest and PROV-O provenance record.
- OpenTimestamps and Zenodo DOI scaffolding (pending mint/notarisation).
- Zistgah registry seed (by-reference).
